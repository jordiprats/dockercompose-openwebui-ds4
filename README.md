# ds4 ROCm with openwebui as interface

- Log into your Open WebUI dashboard as an administrator.
- Navigate to Settings > Connections.
- Under OpenAI API, click the + icon or edit the existing fields.
- Set the API Base URL to http://ds4:8000/v1.
- You can use any placeholder text (e.g., ds4-secret) into the API Key field, as your local ds4 instance does not require authentication.
- Click Save.
